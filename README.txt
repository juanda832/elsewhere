ELSEWHERE V16 — COMPLETE SPA BUILD

HOW TO OPEN
1. Open index.html.
2. Navigation uses JavaScript hash routes such as #/park, #/attractions/infinite-transit and #/shop/price-index.
3. Clicking a route replaces only the content inside #app; the full page does not reload.

CACHE NOTE
V16 does not install a service worker while the project is still being edited. It unregisters previous Elsewhere service workers and clears old Elsewhere caches to avoid stale files from older builds.

DEPLOYMENT
Deploy the complete elsewhere-v16 folder. Do not upload only index.html because the site also needs catalog-v16.js, elsewhere-v16.js, elsewhere-v16.css and the assets folder.
